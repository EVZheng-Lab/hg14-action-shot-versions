# 动作镜头版本全览（Hell Grind / Cully Hill Boys）

抖音「EV的硅基培养皿」·《Hell Grind》深度拆解 第 14 期《动作戏的力度与子弹时间》配套资料。

从 Higgsfield 公开的两部 AI 电影《Hell Grind》（HG）和《Cully Hill Boys》（CHB）的全部生成记录里，挑出抽卡最多的 6 个动作镜头：

- CHB：104 冲出门躲吧台 / 31 Tobin 开枪 1000fps / 99/5 Dmitry 烟雾对射
- HG：39 A-B 斩断立柱 / 51 弹弓炸石像 / 36 从墙上坠落

每个镜头可以看到：各版本提示词怎么改、每版的生成视频、成片里用的那段，以及部分镜头在 Seedance 2.5 下的重跑。

## 怎么看

- 在线打开：仓库的 GitHub Pages 页面（见右侧 About 链接）。
- 本地打开：下载仓库后，在文件夹里运行 `python -m http.server`，浏览器打开 `http://localhost:8000/`。直接双击 index.html 可能因为浏览器限制加载不出数据。
- 页面里的“备注”只存在你自己的浏览器里。
